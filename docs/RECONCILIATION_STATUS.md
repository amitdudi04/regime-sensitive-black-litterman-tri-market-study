# Reconciliation Status

## Current public-main policy

The default branch is intended to contain only the defensible research-facing path.

Historical experiment snapshots, stale result families, the legacy optimizer/backtester, the old GUI, mock SOE execution code, synthetic-fallback robustness code and stale research figures have been removed from main and preserved in Git history plus the branch:

historical/pre-defensibility-cleanup-2026-10-03

## Canonical executable path

The supported execution path is:

python -m pipelines.paper_v1_pipeline

The backward-compatible entry point is:

python -m pipelines.run_tri_market_pipeline

Both point to the cleaned paper-v1 reconciliation implementation.

## Output separation

- results/reference/ = values reported in the existing working paper.
- results/recomputed/ = outputs generated by the cleaned pipeline.

The repository does not silently treat reference tables as fresh recomputations.

## Published-paper reproduction status

The existing working paper reports the 12.99% / 0.650 US Black-Litterman result family.

The cleaned code has not yet been certified as an independent reproduction of that table because the public repository does not contain the historical ETF capitalization/AUM series implied by the paper's market-capitalization prior.

The reconciliation code therefore uses an explicit equal-weight equilibrium proxy until a justified prior-weight series is supplied.

## Corrections incorporated into main

- paper errata added for unresolved claims and methodology differences.

## Working paper

The existing paper is retained as a pre-reconciliation working paper, not presented as a fully reconciled final artifact.

See PAPER_ERRATA.md before interpreting its strongest claims.

## CI

The repository includes unit-test CI for pull requests and pushes to main. A successful CI run verifies the deterministic unit tests, not the external-data empirical rerun.
